HARROW'S WAKE - FREE DEMO (PC / laptop)
Apex Horror 2026 Game Jam entry

HOW TO PLAY
  Windows: unzip everything, then run HarrowsWake.exe.
           Keep the data_HarrowsWake folder next to the exe.
           If Windows SmartScreen warns you, click "More info" then "Run anyway"
           (the game isn't code-signed).
  Linux:   unzip, then run ./HarrowsWake.x86_64 (chmod +x it if needed).
  Headphones recommended. Play in the dark.

KEYBOARD + MOUSE
  Move ............ WASD / arrow keys
  Run / hold breath  Shift
  Examine / select . E, Space or Enter
  Aim .............. K or right mouse
  Fire ............. J or left mouse
  Quick turn ....... Q
  Items ............ Tab or I
  Flashlight ....... F
  Pause / back ..... Esc (P also pauses)
  Fullscreen ....... F11 or Alt+Enter (also in Settings)
  Controls help .... F1     CRT scanlines ... F2

GAMEPAD (Xbox layout)
  Move: left stick / D-pad   Examine: A   Run: B   Aim: RB   Fire: X
  Quick turn: Y   Flashlight: LB   Items: Back   Pause: Start

SETTINGS
  Tank (classic) or Modern controls, brightness, volume, CRT, shadows,
  door scenes and fullscreen. Saved automatically.
